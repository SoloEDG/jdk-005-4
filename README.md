# 青禾农场

安装：`npm install`

本地启动：`npm run dev`

类型检查 / 构建 / 逻辑测试：`npm run typecheck` · `npm run build` · `npm test`

Docker 启动：`docker compose -p pinru-jdk005-1113 up --build`，打开 http://localhost:18025 。

## 养蜂与授粉

- **蜂箱是设施**：在工坊用 6 玉米 + ¥25 制作，领取后选一块空地放置；蜂箱占地，该格不能再种作物，可随时移动。
- **出勤规则**：蜜蜂只在晴天和小雨天的 8:00–17:00 出勤，大风天停飞但不回退任何进度；每箱每天最多 3 次访问，按曼哈顿距离就近选择半径 3 格内、已开花且本轮尚未授粉的田块。
- **授粉与产量**：授粉记录写在当轮作物上（再生作物同轮保留，移除后新作物重新等待授粉），收获时形成独立的高品质批次（品质 +1，最高 ★3）。每次访问同时在蜂箱里存一份蜂蜜，手动取蜜入仓。
- **蜂蜜礼盒**：工坊用 2 份蜂蜜制作蜂蜜礼盒，村庄订单会收购礼盒、蜂蜜与高星授粉作物。
- **移动与持久化**：移动蜂箱只改变之后的飞行范围，不抹掉已授粉记录；每日访问次数随存档保存，恢复后不会在同一天重复计算。所有结算都在逐小时 tick 内以纯函数完成，逐小时推进与「下一天」按钮结果完全一致。
